## ✨ Features

- **⚡ Real-Time Compute Shaders:** Powered by WebGPU / Modern Web Audio for ultra-smooth 60 FPS performance.
- **🎵 Reactive Audio Visualization:** Particles react dynamically to real-time voice, microphone input, or music frequencies.
- **🎛️ Cyberpunk Glassmorphism UI:** Sleek, frosted glass controls for effortless interactive tuning.
- **🌌 Interactive Particle Fields:** Dynamic physics-driven particle systems with custom color palettes and glowing plasma arcs.

---

## 🛠️ Tech Stack

- **Frontend Framework:** Vite + TypeScript
- **Graphics & Audio:** WebGPU, WGSL Shaders, Web Audio API
- **Deployment & Hosting:** Vercel
